# Example.com – setting up saved-search alerts

Status: template · Terms of use checked: YYYY-MM-DD

1. Sign in with the email address Claude reads through the Gmail connector.
2. Search for what you want, using the site's own location picker.
3. Save the search and switch on email alerts (instant if offered).
4. Tell Claude when done; setup records the exact sender address from the first alert.

## If no alerts arrive

- Check Spam and Promotions.
