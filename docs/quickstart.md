# Quick start

Pick the guide for where you use Claude. Both take about 15 minutes and end with hourly alerts and a weekly summary.

| You use Claude in | Guide |
|---|---|
| claude.ai, or the Claude desktop or mobile app | [quickstart-claude-app.md](quickstart-claude-app.md) |
| Claude Code (terminal, IDE, or the desktop app's Code tab) | [quickstart-claude-code.md](quickstart-claude-code.md) |

Both guides need:

- a Claude Pro, Max, Team or Enterprise plan;
- the Gmail account that receives your listing-site alerts;
- a free GitHub account for your private settings repository.
